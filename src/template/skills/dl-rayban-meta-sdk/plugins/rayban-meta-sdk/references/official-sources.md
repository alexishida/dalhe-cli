## Snapshot facts used by this skill

Checked 2026-09-22:

- Official Android and iOS repository READMEs reference SDK 0.9.0.
- Android artifacts are published under `com.meta.wearable` on Maven Central.
- iOS uses Swift Package Manager from the official repository.
- Meta provides Claude Code and Codex plugin manifests in its public repos.
- The Wearables MCP is documented as public and no-auth, with `search_dat_docs` and `search_webapps_docs`.
- Web Apps are specific to Meta Ray-Ban Display.
- Meta's Web App toolkit documents a 600x600 viewport and D-pad/keyboard-style navigation constraints.
- Device Access Toolkit remains described as Developer Preview in official repository documentation at this snapshot.

If any live documentation contradicts this file, follow the live official documentation.
